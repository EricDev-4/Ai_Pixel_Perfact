# ENDESGA 32 기반 v2 후보

사용자 승인 대기. 숲 스테이지 잔디의 중간 밝기와 낮은 채도를 추가하는 32색 후보.

| 변경 | 색 | 대상과 이유 |
|---|---|---|
| 추가 | 따뜻한 올리브 `#83a85c` | 잔디 바탕과 볕이 드는 잎. `#3e8948`보다 밝고 `#63c74d`보다 채도가 낮아 넓은 배경에 쓰기 좋다. |
| 교체 대상 | 중간 자홍 `#b55088` | 보라 램프의 중간 단계. 확인한 성·배경 PNG와 캐릭터 앵커·시트 총 10장에서 이 값과 정확히 일치하는 불투명 픽셀이 없었다. 보라색 마법·천을 그릴 때는 중간 명암이 한 단계 줄어든다. |
