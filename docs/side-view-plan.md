# 옆모습 1방향 제작 계획과 Pixel Engine 플랜별 생성량

기준일 2026-11-18. 가격은 pixelengine.ai 공식 가격표, API 문서, 약관 기준이며 바뀔 수 있습니다.

## 1. 방식

- 캐릭터는 **왼쪽(west)을 보는 옆모습 한 방향**만 만듭니다. 오른쪽은 게임 엔진에서 좌우 반전합니다.
- 화면이 탑다운이어도 캐릭터는 좌우로만 바라봅니다. 위·아래로 이동할 때는 마지막에 바라본 좌우 방향 스프라이트를 그대로 씁니다.
- 앵커(정지 이미지)는 GPT Image(Codex)로 1장 만들고, 동작은 Pixel Engine이 그 앵커를 그대로 움직여 만듭니다.
- 탑다운 4방향(S, W, N + E 반전)보다 동작당 생성 횟수가 1/3입니다.

## 2. 캐릭터 종류별 애니메이션 구성

idle은 `sprite.py idle`로 앵커에서 만들어 **크레딧이 들지 않습니다.**

| 동작 | 프레임 | 반복 | 비고 |
|---|---|---|---|
| idle | 8 | 루프 | 무료 (앵커에서 생성) |
| walk | 8 | 루프 | |
| run | 8 | 루프 | |
| attack | 8 | 1회 | 빠른 동작은 중간 프레임 보정 필요할 수 있음 |
| skill | 8–10 | 1회 | 특수 공격 |
| hurt | 6 | 1회 | |
| death | 10 | 1회 | 누운 자세는 키 비교에서 제외 |

| 종류 | 포함 동작 | 유료 생성 동작 수 |
|---|---|---|
| **주인공** | idle, walk, run, attack, skill, hurt, death | 6 |
| **일반 몬스터 / 동료** | idle, walk, attack, hurt, death | 4 |
| **잡몹** | idle, walk, hurt | 2 |
| **NPC** | idle, walk | 1 |

## 3. Pixel Engine 가격

| 항목 | 크레딧 |
|---|---|
| 애니메이션 v1.5 (3–16프레임, pixel 모드 최대 320px) | 26 |
| 애니메이션 v1.1 (2–16 짝수 프레임, 최대 256px) | 20 |
| v1.1 묶음 요청 N개 (`/animate-batch`, 2–10개) | 20 + 12×(N−1) |
| 실패·취소된 작업 | 0 (차감 안 됨) |

| 플랜 | 월 가격 | 월 크레딧 | 비고 |
|---|---|---|---|
| Free | $0 | 100 | 인증 전에는 더 적을 수 있음 |
| Plus | $12 | 2,000 | |
| Pro | $20 | 4,000 | |
| Ultra | $60 | 12,000 | |

- 구독 크레딧은 매달 다시 채워지고 **다음 달로 넘어가지 않습니다.**
- 따로 구매한 크레딧(100크레딧 = $1)은 만료되지 않지만 구독보다 약 2배 비쌉니다.
- 상업적 이용은 모든 플랜에서 가능합니다. 업로드와 결과물은 기본적으로 학습에 쓰이므로 `training_opt_out`(sprite.py가 자동으로 보냄)이나 계정 설정으로 끕니다.

## 4. 캐릭터당 크레딧

재생성을 고려해 **동작당 평균 1.5회** 생성으로 계산했습니다(테스트에서 걷기는 1회에 성공, 공격은 보정이 필요했음). 모델은 v1.5(26크레딧) 기준입니다.

| 종류 | 유료 동작 | 생성 횟수 | 크레딧 |
|---|---|---|---|
| 주인공 | 6 | 9 | 234 |
| 일반 몬스터 / 동료 | 4 | 6 | 156 |
| 잡몹 | 2 | 3 | 78 |
| NPC | 1 | 1.5 | 39 |

## 5. 플랜별 월 생성 가능 캐릭터 수 (v1.5)

| Free (100) | 3 | 0 | 0 | 1 | 2 |
| Plus (2,000) | 76 | 8 | 12 | 25 | 51 |

### 예시 조합

| 플랜 | 한 달 예시 | 사용 크레딧 |
|---|---|---|
| Plus | 주인공 1 + 일반 몬스터 6 + 잡몹 6 + NPC 6 | 234 + 936 + 468 + 234 = 1,872 |

### v1.1 묶음 요청을 쓰면

v1.1을 10개씩 묶으면 10개에 128크레딧(개당 12.8)이라 v1.5보다 약 2배 많이 만듭니다. 대신 짝수 프레임만 되고 품질이 v1.5보다 낮을 수 있습니다. 잡몹·NPC처럼 단순한 동작에 맞습니다.

| 플랜 | v1.1 묶음 애니메이션 수 |
|---|---|
| Free | 7 |
| Plus | 156 |
| Pro | 312 |
| Ultra | 937 |

## 6. 플랜 선택 기준

- **시험만:** Free. v1.5 3회.
- **한 달 캐릭터 10개 안팎:** Plus. 개당 약 $0.16.
- **Plus 크레딧이 모자랄 때:** Pro. $8 더 내고 크레딧 2배, 개당 약 $0.13.
- **대량 생산:** Ultra. 개당 단가는 Pro와 같으므로 양이 필요할 때만.

크레딧이 이월되지 않으므로, 필요한 양보다 큰 플랜은 낭비입니다.

## 7. 크레딧 외 비용

- 앵커 생성은 Pixel Engine이 아니라 GPT Image(Codex, ChatGPT 구독)를 씁니다. 캐릭터당 1장, 재생성 1회까지.
- 공격 등의 중간 프레임 보정도 GPT Image로 합니다(`inbetween`).
- Claude는 프롬프트 작성, 검수, 후처리에 씁니다.
