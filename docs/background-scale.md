# 숲과 강 스테이지 배경 규칙

## 화면과 기준 크기

1920×1080 화면을 기준으로 배경 원본은 **960×540 도트**다. PNG에서 1도트는 1px이며 엔진에서 Point 필터로 정수 2배 표시한다. 텍스처 압축과 밉맵을 끈다. 좌표는 원본 도트 기준이며 왼쪽 위가 `(0, 0)`이다.

| 게임 요소 | 화면 비례 기준 |
|---|---|
| 견습 기사 | 실루엣 31×40도트. 화면에서는 62×80px |
| 일반 적 | 키 28–48도트 |
| 대형 적 | 키 64–96도트 |
| 현재 성 | 투명 여백을 뺀 실루엣 180×124도트. 기사 키의 3.1배이며 배경 너비의 18.75% |

일반 적과 대형 적의 범위는 프로젝트의 기존 크기 등급을 따른다. 기존 스프라이트인 바나나(20×46)와 페드로(27×39)는 크기 검증에 사용했다. 적 역할이 확정된 에셋은 확인되지 않았다.

## 첫 스테이지 배치

| 영역 | 원본 좌표와 적용 기준 |
|---|---|
| 숲 | 기준선 `y=104`. 뿌리·덤불 끝은 `y=117`까지 허용 |
| 잔디 전투 공간 | 시각적으로 숲 아래에서 석축 위까지 연속된다. 전투 발 위치는 `x=184–959`, `y=230–422` |
| 성 | 독립 스프라이트의 좌상단을 `(0, 206)`에 놓는다. 바닥은 `y=329`, 성문 바닥은 `y≈327` |
| 석축 | 제작 기준선 `y=434`. 완성본의 잔디·석재 경계는 `y=431–436`에 걸쳐 있으며 대부분의 열이 석재로 바뀌는 첫 줄은 `y=433` |
| 강 | `y=482–539`. 필요 시 HUD를 이 위에 별도 레이어로 배치 |

- 전투 상단에 서는 96도트급 적의 머리는 `y≈134`까지 올라간다. 숲 장식 끝에서 약 16도트가 남는다. 전투 하단의 발 기준점과 석축 기준선 사이에는 12도트가 남는다.
- 성과 유닛의 깊이 정렬은 발 또는 바닥 y좌표를 쓴다. 오른쪽에서 진입하는 적의 접근 경로는 성문 바닥 높이 부근으로 모은다. 성 아래를 지나는 경로는 막고, 유닛의 도착 판정은 성문 앞에 둔다. 현재 성문 아트의 폭은 기사 실루엣보다 좁다.
- 덤불은 숲 끝에서 12–20도트, 변두리 돌은 4–8도트, 작은 풀은 4–6도트, 큰 풀 포기는 10–13도트 높이를 기준으로 삼는다. 작은 돌과 풀은 전투 공간 가장자리에 모으고 중앙에는 드물게 배치한다.
- 배경 PNG에는 숲, 잔디, 석축과 물만 담는다. 성, 캐릭터, 적, UI, 전투 효과는 엔진에서 필요한 위치에 배치한다.

## 제작과 검수

Herdr의 Claude와 성·캐릭터 실루엣을 대조해 좌표를 정했다. Softmilk 32 버전은 기존 배경 구도와 새 팔레트의 스와치로 GPT Image에서 다시 생성했다. 1672×941 생성 원본을 목표 격자에 직접 샘플링한 뒤 재질 마스크와 밝기 구간으로 재칠했다. 석축과 강의 경계는 평평한 줄을 도트 단위로 다듬어 맞췄다.

저장한 인덱스 PNG를 다시 열어 960×540, 전체 13색, 원경 6색, 근경 10색, 팔레트 밖 색 0개, 반투명 픽셀 0개를 확인했다. 숲 재질은 `y=110`까지 나타나며, 강은 `y=482`부터 시작한다. 성과 기존 캐릭터를 원본 크기로 올려 배치를 별도로 검수했다.

현재 잔디 바탕은 `#82aa28`이다. 숲 아래에 덤불과 양치류를 배치하고, 전투 공간에 작은 들꽃, 돌과 풀 포기를 드문드문 배치했다. 이전 ENDESGA 원본과 올리브색 시안은 기존 작업 폴더에 보관한다.
